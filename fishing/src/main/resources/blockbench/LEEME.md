# Modelos de Blockbench de RPGRoll-Fishing

Un `.bbmodel` por modelo, con la textura dentro (formato "Java Block/Item"). Sirven para retocarlos:
se abren en Blockbench, se cambian y se exportan como modelo de Java a un pack propio.

Los que trae el plugin ya van en su resource pack (`rpgroll_fishing:<tipo>/<id>`); para usar uno retocado,
ponlo en tu pack con otro nombre y cambia la clave `model:` del YAML.
